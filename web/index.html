反向代理规则

按「域名 + 路径前缀」匹配请求；路径前缀会从上游路径中剥离。支持 *.example.com 泛域名与 WebSocket。

新增规则

端口转发

转发由内核 DNAT 直接完成，不占进程内存，并发再高也只是消耗连接跟踪表。规则只写进本工具自己的链（LP_FWD / LP_ACL / LP_IN），出问题可整体清空，不动系统已有规则。需要以 root 运行。
开启本页后，反代监听端口（以及勾选「HTTP 自动跳转」时的 HTTP 端口）会一并写进 INPUT 放行—— 这样路由器自带的 IPv6 防火墙全开时，也只有这几个端口和下面规则里的端口能从外网进来；管理面板端口不会被放行。

生效状态

自动证书

走 DNS-01 验证：用阿里云解析自动添加 TXT 记录，不占用 80 端口，不和反向代理抢路径，还支持泛域名。 证书自动保存在 安装目录/certs，签发后直接生效，不用填目录、不用上传文件。剩余天数低于阈值时自动续期。

证书状态

阿里云 DDNS

只支持阿里云解析（AliDNS）。AccessKey 建议用子账号并只授予 AliyunDNSFullAccess。

解析记录

「域名」填主域名（example.com），「主机记录」填 @（根域）、*（泛解析）或 home 这类前缀。 也可以直接在域名栏写完整域名 *.example.com，保存时会自动拆开。

同步状态

网络唤醒

魔术包走 UDP，被唤醒设备关机也能收到

点「唤醒」会给这台设备的每块网卡各发一组魔术包。跨网段时把「广播地址」填成目标网段的广播地址（如 192.168.31.255）， 同网段留空即可。唤醒后设备通常 10~30 秒开机，面板不会自动检测在线状态。

HTTPS

      
证书由「证书」页自动申请并保存到 安装目录/certs，
        这里不用填任何证书路径——开启后自动加载、自动按域名（SNI）匹配，签发或续期后自动热加载。

      

        
        
      

      

        
        
      

      
公网端口填外网实际访问的 HTTPS 端口（例如反代监听 8686 并从外网 8686 进来，就填 8686），跳转时会带上它。

        浏览器里手抖写了 http://域名:8686 也没关系：反代端口会自己认出这是明文请求并跳到 https://，
        「额外 HTTP 监听地址」留空就行。只有需要另开一个端口（比如能用的 80）收 HTTP 时才填，而且不要填成反代端口本身。

访问控制

      
路由器自带的 IPv6 防火墙能挡端口，但挡不住「IP:端口 直接打开面板」。打开下面这项后，
        外网用 IP（v4/v6）访问反代或面板一律 403，只认反向代理规则里配置的域名——
        配合「端口转发」页的自动放行，就是「只有域名能进」。内网与本机（127.0.0.1）不受影响，始终可以访问，日常使用无需域名。

      

        
        
      

      
面板端口（18080）不会写进防火墙放行名单，外网本来就够不着；这项开关是应用层的第二道保险。

    


    

      
安全入口

      
填一个只有你知道的路径，例如 /x7k2m。开启后外网必须访问
        https://你的域名:端口/x7k2m 才能进，直接打开 https://你的域名:端口/ 一律返回 404，
        看起来就像这个端口上没有服务——端口扫描器扫到了也进不来。

        进过一次之后，浏览器会拿到一张 7 天有效的通行票据，页面里的 /static、/api 等资源照常加载，不用每次重输。
        内网与本机始终可以直接访问，不会把自己锁在外面；改了路径旧票据立即失效。

        另外，在「端口转发」页勾选「转发端口敲门放行」后，访问过这个入口的来源网络也会被加进转发端口的放行名单
        （IPv6 按 /64 记录，7 天有效）——出门前/到店里先开一次网页，mstsc 等直连端口的应用就都能用了。

      

        
      

      

        
      

    


    

      
配置备份

      
导出为一个 .zip 压缩包，里面包含全部设置（反向代理、DDNS、端口转发、访问控制）以及证书文件和私钥，
        换机器或重装后直接导入即可使用，不需要重新签发证书。
        注意：包里包含阿里云 AccessKey 与证书私钥，请妥善保管。导入会立即生效并覆盖当前配置，导入前会先校验，不合法的包不会生效。
