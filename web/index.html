新增规则

端口转发

转发由内核 DNAT 直接完成，不占进程内存，并发再高也只是消耗连接跟踪表。规则只写进本工具自己的链（LP_FWD / LP_ACL / LP_IN），出问题可整体清空，不动系统已有规则。需要以 root 运行。
开启本页后，反代监听端口（以及勾选「HTTP 自动跳转」时的 HTTP 端口）会一并写进 INPUT 放行—— 这样路由器自带的 IPv6 防火墙全开时，也只有这几个端口和下面规则里的端口能从外网进来；管理面板端口不会被放行。

自动证书

走 DNS-01 验证：用阿里云解析自动添加 TXT 记录，不占用 80 端口，不和反向代理抢路径，还支持泛域名。签发后写入证书目录并热加载，剩余天数低于阈值时自动续期。

证书状态

阿里云 DDNS

只支持阿里云解析（AliDNS）。AccessKey 建议用子账号并只授予 AliyunDNSFullAccess。

解析记录

「域名」填主域名（example.com），「主机记录」填 @（根域）、*（泛解析）或 home 这类前缀。 也可以直接在域名栏写完整域名 *.example.com，保存时会自动拆开。

监听与面板

HTTPS

支持单张默认证书，或一个目录（按 SNI 自动匹配，文件名用域名，如 nas.example.com.crt + .key）。更换证书后按「重载证书」即可，无需重启。

公网端口填外网实际访问的 HTTPS 端口（例如路由器把 443 映射到 8443，就填 8443），跳转时会带上它。

访问控制

路由器自带的 IPv6 防火墙能挡端口，但挡不住「IP:端口 直接打开面板」。打开下面这项后， 凡是用 IP 访问的一律 403，只认反向代理规则里配置的域名——配合「端口转发」页的自动放行，就是「只有域名能进」。

开启后请确认已有一条反代规则指向 http://127.0.0.1:8081，否则只能靠 SSH 隧道进面板救急。
